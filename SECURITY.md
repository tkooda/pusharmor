# Security policy

## Reporting a vulnerability

Report security problems in a public GitHub issue
(https://github.com/tkooda/pusharmor/issues/new) or privately with GitHub
private vulnerability reporting
(https://github.com/tkooda/pusharmor/security/advisories/new).

Include the affected part (site, Worker, Chrome or Firefox extension, Android
or iPhone app), the version, and the steps to reproduce.

The threat model is described at https://pusharmor.com/security.

## Supported versions

Only the latest release of each part gets security fixes.
