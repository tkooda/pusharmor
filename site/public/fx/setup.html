Set up PushArmor for Firefox

The PushArmor add-on uses a background script on PushArmor.com (service worker) to receive encrypted messages when its own push connection is not available, and always on Firefox for Android. This needs notifications for PushArmor.com. The background script only passes along encrypted messages it cannot read to the add-on.
