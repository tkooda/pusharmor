How to use PushArmor

1. Install

Get the Android app, the iPhone app, the Chrome extension or the Firefox add-on from the download page. Each install is one peer of your account.

2. Sign in

Sign in with an email code, with Google or with Apple. Use the same email address on every peer, so all your peers join the same account. Only email addresses with plain ASCII characters are supported.

With an email code, enter the 6-character code from the email. Nothing happens unless this code is entered within 15 minutes. If you did not request it, ignore this email.

3. Pair your peers

A pairing stays open for 14 days. Each pairing shows how much time is left. Tap Pair on a peer, then compare the pairing fingerprint on both peers.

The pairing fingerprint is 4 characters. It must be the same on both screens. If it is not the same, do not confirm the pairing.

4. Send

Share a link or text to PushArmor, or use the PushArmor menu in the browser, then pick a peer. With the "All" setting on (the default), you can also pick All to send to every paired peer. You can turn the All option off in Settings.

Sync and Refresh fetch the peer list again. After a tap they stay grey for 60 s.

Notices about pairing

"A new peer wants to pair" means someone tried to pair with this device and the try failed or came from an unknown peer. Ignore it unless you started a pairing. If a Reply button appears, this device has already answered 10 tries in 24 hours; tap Reply only if you started that pairing.

"Name wants to pair again. Tap Cancel pairing on its row, then pair." means that this device still holds an earlier, unfinished pairing with that peer. On the device that shows the notice, tap Cancel pairing on that row, then pair again. Use Remove only to really remove a peer: that peer is removed from the account; it signs in again with a new identity and pairs again with each of your peers.

More answers are on the support page.
