F-Droid repository

Add our repository to F-Droid to install PushArmor and get updates. On your Android device, tap Add to F-Droid. Works in F-Droid, Droid-ify, and Neo Store.

Or add this repository URL by hand:

https://fdroid.pusharmor.com/repo

Check that F-Droid shows this repository fingerprint (SHA-256):

262c4f2e9a0220ed48181a5c8650dd742372b220e628fe10e7eea2e9fe6ce4e3

Obtainium

Obtainium installs and updates PushArmor from GitHub Releases. Tap Add to Obtainium.

Or add this URL in Obtainium, turn on "Include prereleases", and set "Filter links by regex" to foss.apk:

https://github.com/tkooda/pusharmor

APK files

Each release on GitHub Releases has two Android APKs.

  • foss: for UnifiedPush only, no Google code.
  • play: for Google push (FCM) or UnifiedPush.

Check a downloaded APK against these SHA-256 values and the signing certificate fingerprint.

To check the certificate of a downloaded APK, run this command and compare the SHA-256 digest. Replace the file name with the name of your file:

apksigner verify --print-certs pusharmor-0.0.25-foss.apk

Command line

The command-line client runs on Windows, macOS, and Linux. It needs Python 3.9 or later. We recommend that you install it from PyPI with pipx:

pipx install PushArmor

Or download the single file pusharmor.py from GitHub Releases. It needs the cryptography package. On Debian and Ubuntu:

sudo apt install python3-cryptography

On RHEL, Fedora, and related systems:

sudo dnf install python3-cryptography
