F-Droid repository

On your Android device, tap Add to F-Droid. Works in F-Droid, Droid-ify, and Neo Store.

Or add this repository URL by hand:

https://fdroid.pusharmor.com/repo

Add URL (includes the fingerprint):

fdroidrepos://fdroid.pusharmor.com/repo?fingerprint=262c4f2e9a0220ed48181a5c8650dd742372b220e628fe10e7eea2e9fe6ce4e3

Check that F-Droid shows this repository fingerprint (SHA-256):

262c4f2e9a0220ed48181a5c8650dd742372b220e628fe10e7eea2e9fe6ce4e3

Obtainium

Tap Add to Obtainium (Google/UnifiedPush) or Add to Obtainium (UnifiedPush only).

To switch later, tap the other button. The switch installs with the next update.

Command line

Runs on Linux, macOS, and Windows.

Install the command-line client from PyPI with pipx:

pipx install PushArmor

Or download pusharmor.py, which needs the cryptography package:

sudo apt install python3-cryptography
sudo dnf install python3-cryptography
