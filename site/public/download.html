Android APKs from GitHub

Each release on GitHub Releases will have two Android APKs:

  • play: for Google push (FCM) or UnifiedPush.
  • foss: for UnifiedPush only, no Google code.

Check a downloaded APK against these SHA-256 values.

FileSHA-256
pusharmor-0.0.X-play.apkComing soon
pusharmor-0.0.X-foss.apkComing soon

To check the certificate of an installed or downloaded APK, run apksigner verify --print-certs on it and compare the SHA-256 digest.
