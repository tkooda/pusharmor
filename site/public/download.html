F-Droid repository

Add our repository to F-Droid to install PushArmor and get updates. On your Android device, tap Add to F-Droid, or scan this QR code in the F-Droid app. Works in F-Droid, Droid-ify, and Neo Store.

Or add this repository address by hand:

https://fdroid.pusharmor.com/repo

Check that F-Droid shows this repository fingerprint (SHA-256):

262c4f2e9a0220ed48181a5c8650dd742372b220e628fe10e7eea2e9fe6ce4e3

Android APKs from GitHub

Each release on GitHub Releases will have two Android APKs. Obtainium can install and update them from this address.

https://github.com/tkooda/pusharmor
  • play: for Google push (FCM) or UnifiedPush.
  • foss: for UnifiedPush only, no Google code.

In the file names, <version> stands for the release number. Check a downloaded APK against these SHA-256 values and the signing certificate fingerprint.

FileSHA-256
pusharmor-<version>-play.apkComing soon
pusharmor-<version>-foss.apkComing soon
Signing certificate (SHA-256 fingerprint)Coming soon

To check the certificate of a downloaded APK, run this command and compare the SHA-256 digest. Replace the file name with the name of your file:

apksigner verify --print-certs pusharmor-<version>-play.apk

Command line

The command-line client runs on Linux and macOS. It needs Python 3.9 or later. We recommend that you install it from PyPI with pipx:

pipx install PushArmor

Or download the single file pusharmor.py from GitHub Releases. It needs the cryptography package. On Debian and Ubuntu:

sudo apt install python3-cryptography

On RHEL, Fedora, and related systems:

sudo dnf install python3-cryptography
