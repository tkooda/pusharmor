Security and threat model

Your devices don't need to trust our relay server. Messages are encrypted on your device, and can only ever be decrypted by your own paired devices. Each app and add-on checks everything the server sends, so the server cannot change a message or pose as one of your devices. Each device makes two key pairs (P-256), one for signing (ECDSA) and one for encryption (HPKE), and the private keys used to decrypt and sign messages never leave it. Where the device supports it, they are kept in its hardware key storage (the Secure Enclave on iPhone, the Android Keystore on Android). (The one exception is a short-lived throwaway key that the web delete-account page holds in your browser tab while you log in with Google or Apple. It is not a device key, and it cannot read messages.)

The push service and our relay server can show a notification with text of their choosing on every platform; verified content appears only after your device decrypts it.

The push service sees the size of a message (padded to a few standard sizes), not its content.

How devices trust each other

Two devices trust each other only after you pair them by verifying that the 4-character pairing fingerprint is identical on both screens.

The pairing fingerprint is not a code sent to your devices, and it is never sent over the network. Pairing has you compare a short code on both screens (short authentication string, SAS). Each device first commits to its values by sending only their SHA-256 hash, and reveals them after it has seen the other device's hash (commit-then-reveal). Each device then computes the 4-character fingerprint on its own, from both devices' public keys and a fresh random value from each device. No one, including our relay server, can steer the result.

Every message is signed by the sending device and checked by the receiving device; repeated or old messages are ignored (replay protection). A message that fails this check is never shown; History lists it as "PushArmor received a message it could not read". Messages you read inside PushArmor passed this check. A notification is only a prompt: if one looks wrong, open PushArmor and read the message there.

Reporting a security problem

Report it privately with GitHub private vulnerability reporting. Please do not open a public issue for a security problem. The source code is public on GitHub.
