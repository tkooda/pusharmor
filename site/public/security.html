Security and threat model

PushArmor is built so that our own server does not need to be trusted with your messages. We treat the server (a Cloudflare Worker) as hostile: the apps and add-ons check everything it returns. Keys are made on each device and the private keys never leave it.

The push service and the Worker can show a notification with text of their choosing on every platform; verified content appears only after your device decrypts it.

The vendor sees the size bucket and the urgency level of a message, not its content.

How peers trust each other

Two peers trust each other only after you pair them and compare the 4-character pairing fingerprint on both screens. A forged pairing succeeds with a chance of about 1 in a million per try, and each failed try shows a notice on the other peer. Every message is signed by the sending peer and checked by the receiving peer; repeated or old messages are dropped.

Reporting a security problem

Report it privately with GitHub private vulnerability reporting, or use the contact in security.txt. Please do not open a public issue for a security problem. The source code is public on GitHub.
