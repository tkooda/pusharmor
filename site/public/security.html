Security and threat model

Your devices don't need to trust our relay server. Messages are encrypted on your device, and can only ever be read by your own paired devices. Each app and add-on checks everything the server sends, so the server cannot change a message or pose as one of your devices. Keys are made on each device and the private keys never leave it.

The push service and our relay server can show a notification with text of their choosing on every platform; verified content appears only after your device decrypts it.

The vendor sees the size of a message (padded to a few standard sizes, called size buckets) and its urgency level, not its content.

How devices trust each other

Two devices trust each other only after you pair them and compare the 4-character pairing fingerprint on both screens. This check stops a fake pairing in all but about 1 in a million tries, and each failed try shows a notice on the other device. Every message is signed by the sending device and checked by the receiving device; repeated or old messages are dropped.

Reporting a security problem

Report it privately with GitHub private vulnerability reporting, or use the contact in security.txt. Please do not open a public issue for a security problem. The source code is public on GitHub.
